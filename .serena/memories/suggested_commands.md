# Suggested Commands

## Project Commands (Run inside `E:\Rox\LegalSaathi`)
- `npm run dev`: Start Next.js development server with Turbopack (`http://localhost:3000`)
- `npm run build`: Production build via `next build`
- `npm run start`: Start production server
- `npm run lint`: Run ESLint check across all files
- `npx tsc --noEmit`: Run TypeScript type-checker without emitting code

## Windows Shell Conventions
- PowerShell is the default shell.
- Use semicolon or sequential commands rather than Unix-style operators where appropriate.
- Working directory must be within `E:\Rox\LegalSaathi` for project-specific operations.
